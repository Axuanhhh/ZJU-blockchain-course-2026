# 运行、检查与录制演示

## 最快启动（Windows）

在项目根目录打开 PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

打开 http://127.0.0.1:3000。脚本自动安装缺失依赖、启动本地链、在需要时部署合约、启动前端。服务隐藏运行，日志位于 `.runtime/`。该目录不提交到 Git。

首次启动并同时跑一轮 20 用户模拟：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1 -Simulate
```

已有节点上重新部署：加 `-Redeploy`。这会生成一套新合约地址，不会删除旧合约。修改合约后也要重新部署。

停止由启动脚本创建的服务：

```powershell
powershell -ExecutionPolicy Bypass -File .\stop.ps1
```

## 按按钮完成一次操作

1. 在左侧选择一个本地账户，点击“连接所选账户”。手机窄屏时使用页面上方“连接本地演示”。本地模式直接使用 Hardhat 已解锁账户，所有操作都是真实 RPC 交易。
2. 在水龙头中分别领取 TKA、TKB。每个地址每小时领取一次，每次 10,000 个。若账户已参加模拟而处于冷却期，可以使用已有余额，不必再次领取。
3. 初始已有 TKA/TKB 池子，部署者投入 1,000/1,000。选择“流动性与 NFT”，分别输入最大投入，点击添加。首次授权和添加会各自发送交易。
4. 页面显示新的 NFT、创建时间、份额及当前可赎回代币。
5. 在左侧切换另一账户并重新点击连接，领取代币后完成一次兑换；点击成功提示中的“查看交易”，查看真实交易哈希、区块及 Gas。
6. 切回提供流动性的账户，在 NFT 卡片点击“赎回并销毁”。检查余额增加，NFT 消失。
7. 交易池页可以用两个其他已部署的标准 ERC20 地址建池。初始 A/B 已存在，再次创建会被拒绝。没有流动性的新池必须先首次注入，才能兑换。
8. “链上活动”展示真实事件和 20 用户模拟报告。报告文件还包括所有地址的参与情况和每次随机操作的交易哈希。

## MetaMask 演示

- 网络 RPC：`http://127.0.0.1:8545`；Chain ID：`31337`；货币：`ETH`。
- 手动启动节点时，可以从节点终端导入一个本地测试账户；一键启动时对应输出位于 `.runtime/chain.log`。
- 点击“连接 MetaMask”，按钱包提示授权；如果网络错误，应用会提示切换。
- 本地测试账户的公开私钥只能用于本地链，不要将真实资产转入这些地址。
- 节点重启会清空链上数据。重新运行启动脚本会自动重新部署。若 MetaMask 仍缓存了旧链的 nonce，使用钱包提供的活动数据重置功能后重试。
- 自动化验收使用本地账户模式；钱包扩展中的弹窗确认需要你亲自演示。

## 验证命令

```powershell
cd contracts
npm run typecheck
npm test
npm run simulate

cd ..\frontend
npm test
npm run build
npm run test:e2e
```

浏览器测试需要本地链和前端已启动，默认使用电脑已安装的 Chrome。没有 Chrome 时可安装 Playwright Chromium，并设置 `PLAYWRIGHT_CHANNEL=chromium`；也可设置为 `msedge` 使用 Edge。

端到端测试会部署一个额外的 TKC 测试币、创建新池并推进本地链时间一小时，以便重复测试水龙头。它会保存真实界面截图，测试链状态会随之改变。测试只针对本地教学环境。

## 1～2 分钟录制顺序

- 0:00～0:10：展示运行终端、网络与账户。
- 0:10～0:25：领取两种代币，展示余额。
- 0:25～0:50：添加流动性并获得 NFT，展示仓位信息。
- 0:50～1:10：切换另一账户兑换，展示钱包确认/链上回执。
- 1:10～1:30：切回原账户，销毁 NFT 取回资产。
- 1:30～1:50：展示 20 个地址、300 次操作及不变量检查报告。

如果要展示“新建池子”，可另部署一份 TestToken，使用它与 TKA 建池；浏览器验收测试已经覆盖这一流程。运行截图目录为 `docs/screenshots/`。
